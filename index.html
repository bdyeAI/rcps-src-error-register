How this works

Paste a fresh SSWS error extract below any time you re-run the submission. The register reads the school headers (like 0010 BELLE HETH ELEM) to sort every row to the right school, then compares it against what's already tracked here:

• A row that wasn't tracked before is added as Open.
• A row that's still in the new extract keeps whatever status it already had.
• A row that was tracked before but is missing from the new extract is marked Resolved automatically — VDOE no longer flags it, so it's confirmed fixed.

Check the box next to a row to mark it Reviewed (someone's looked at it / working on it) — this is a manual flag, separate from the automatic Resolved detection. Resolved rows can be reopened if one comes back or was marked by mistake.

Matching across submissions is based on the field name and the error detail text together. If the detail text itself changes between runs (for example, an absence-day count that keeps climbing), the row may show up as a new one rather than matching the old one — that's a limitation of matching on text, not a bug. The data here is shared and live: everyone with this page open sees the same register.
